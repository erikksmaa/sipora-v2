# SIPORA Opportunity demo asset pack

Seluruh organizer, orang, dan program bersifat fiktif. Dibuat dengan built-in imagegen, satu gambar per panggilan.

- 8 logo PNG dengan latar transparan (raster bergaya vector, bukan SVG).
- 15 latar poster JPEG 1200×1500 (4:5), tanpa teks.
- 15 crop kartu JPEG 1600×900 (16:9), dari area tengah poster.
- manifest.json: mapping organizer/program dan file.
- prompts.json: prompt generasi.
- manual-copy.json: teks untuk overlay manual. Detail yang belum diberikan tetap null.
- index.html: galeri lokal, dapat dibuka langsung setelah ekstraksi ZIP.

Tambahkan judul di area atas dan metadata di area bawah melalui Canva/Figma. Untuk versi kartu, tambahkan teks sebagai overlay HTML atau desain terpisah; crop kartu tidak mempertahankan area teks atas/bawah poster. Periksa crop saat memakai rasio lain.
