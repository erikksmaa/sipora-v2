# Batch 7C - P001 Logbook

Enam milestone Logbook, tujuh foto JPEG 1200x900. Semua data dan foto bersifat fiktif. Tiga foto baru dibuat dengan built-in imagegen; empat foto digunakan ulang dari dokumentasi A001/A002/A003.

Tanggal dan progres mengikuti brief: 05 Sep 10%, 12 Sep 25%, 20 Sep 45%, 27 Sep 65%, 04 Okt 85%, 10 Okt 100%. Peserta per Activity: A001 20, A002 18, A003 22. Angka ini tidak boleh dijumlahkan sebagai peserta unik. Jumlah peserta A005 dan pencapaian target program 60 orang belum dinyatakan.

Manifest memuat judul, deskripsi, jumlah peserta, progres, status, ID Activity, sumber foto, dan nama file. Index.html dapat dibuka langsung dari hasil ekstraksi ZIP.

Entri adalah catatan milestone. Proposal merencanakan tujuh sesi dan tujuh logbook per sesi; pelaporan ini mengonsolidasikannya menjadi enam milestone. Catat perbedaan ini pada E-LPJ. Tanggal Logbook adalah tanggal pelaporan, bukan pengganti tanggal sesi Activity.

Seeder DemoProgramLogbookSeeder memasang enam entri submitted untuk review, menyalin foto ke disk privat program_logbook_media, dan menghubungkan A001/A002/A003/A005 ke P001. Progres 100% berarti progres dilaporkan, bukan review/evaluasi telah disetujui. A005 tetap menjadi bagian program, tetapi kehadiran dan outputnya belum diberikan.

Jalankan php artisan db:seed --class=DemoProgramLogbookSeeder untuk mengulang konfigurasi di environment local / database sipora. CompetitionDemoSeeder memanggilnya ketika paket ini tersedia. Pemeriksaan ulang memastikan tidak ada entri atau media ganda.
