# SIPORA Activity Documentation

52 fictional activity documentation photographs generated with built-in imagegen for SIPORA demo data. These are synthetic demo assets, not evidence of actual events.

- A001: 6 documentation images.
- A002–A005: 4 documentation images each.
- A006–A015: 3 documentation images each.
- Documentation: JPEG, 1200 × 900, 4:3.
- 15 existing activity covers reused: JPEG, 1600 × 900, 16:9.
- Folder structure: A001–A015 with the requested activity-NNN-documentation-NN.jpg filenames.
- Open index.html to preview the gallery; use manifest.json for asset paths and dimensions.
- prompts.json contains generation prompts and any cleanup prompts.
- logbook-mapping.json maps the six A001 photographs to the example workshop sessions.
- Posters are not included; the documentation brief contains no poster design or event details.
