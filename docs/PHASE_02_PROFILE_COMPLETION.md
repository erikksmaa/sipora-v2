# Phase 2 profile completion

Profile completion is derived at request time and is guidance, not a score or ranking. It is never stored as an editable percentage.

| Item | Weight |
| --- | ---: |
| Full name | 15% |
| Birth date | 15% |
| Gender | 10% |
| Phone | 10% |
| Occupation status | 10% |
| Bio | 10% |
| Primary domicile | 15% |
| At least one interest | 15% |

Profile photo is optional and does not affect completion. Youth age eligibility is calculated separately from birth date and is inclusive from age 16 through 30. Being outside that range does not block account access.
